# 💸 Expenso

> A full-stack web application for managing and tracking expenses.

Expenso is an academic project developed during the third year of my Bachelor's degree in Computer Science at **Haute École Léonard de Vinci**.

The project allowed me to work on both the **frontend and backend** of a web application and understand how the different layers of a full-stack application communicate.

---

## ✨ Features

- Display and manage expenses
- Add new expenses
- Store expense information
- Communication between the frontend and backend through a REST API
- Persistent data storage

---
